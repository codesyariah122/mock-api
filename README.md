# mock-api  
Proyek ini adalah implementasi dari Mock API yang dirancang untuk menyediakan data dummy bagi pengembangan aplikasi. Dengan menggunakan Node.js, proyek ini memungkinkan pengembang untuk menguji dan mengembangkan aplikasi frontend tanpa bergantung pada backend yang sebenarnya.

Fitur Utama:

    Data Dummy: Menyediakan data produk dalam format JSON yang dapat digunakan untuk pengujian dan pengembangan.

    Server Sederhana: Menggunakan Express.js untuk membuat server yang dapat merespons permintaan HTTP dengan data yang telah ditentukan.

    File Konfigurasi: Menggunakan file db.json dan products.json untuk menyimpan dan mengelola data produk.

    Mudah Digunakan: Proyek ini dirancang agar mudah diinstal dan dijalankan, sehingga pengembang dapat segera mulai menggunakannya.
